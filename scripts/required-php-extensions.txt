# Extensions that MUST be present in the finished apache-php / nginx-php
# images. Asserted against `php -m` of the built image by
# scripts/check-php-extensions.sh (wired into the image build workflow).
#
# This list deliberately includes extensions that come from the upstream base
# image as well as the ones our Dockerfiles add. A base-image regression is
# exactly how mysqli went missing from the nginx-alpine variant and how gd
# was lost platform-wide in April 2026 — the guard has to catch both.
#
# Lines starting with # and blank lines are ignored. Matching is
# case-insensitive against whole `php -m` entries.

ctype
curl
dom
fileinfo
filter
iconv
json
mbstring
openssl
pcntl
PDO
Phar
posix

sodium
tokenizer

zlib
